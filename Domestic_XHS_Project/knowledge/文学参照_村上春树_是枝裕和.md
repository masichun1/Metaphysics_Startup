# 文学参照：村上春树 × 是枝裕和

## 村上春树

### 核心笔法
1. **白描冷叙述** — 天大的事也平平地写。情绪不上脸
2. **感官物象** — 触觉、气味、光线、温度承载情绪，不直接抒情
3. **留白** — 不剖析心理，让场景和行为自己说话
4. **比喻惊奇** — 用日常物象建立陌生化比喻（记忆=夕阳下的阴影）
5. **日常中的超现实** — 最寻常的物（井、石头、沙尘暴）进入超自然维度
6. **距离感** — 第一人称保持冷静，不沉溺

### 经典句子
- "回忆会从内侧温暖你的身体，同时又从内侧剧烈切割你的身体。"
- "萤火虫消失之后，那光的轨迹仍久久地印在我的脑际。"
- 不说"我爱你"，说"春天的原野里，你和一只小熊抱着从山坡滚下去。"

## 是枝裕和

### 核心笔法
1. **述而不论** — 不评判，不煽情，呈现生活本真
2. **冰山原则** — 露1/8，藏7/8。留白让观众自己补
3. **日常即诗意** — 食物、天气、家务都是叙事
4. **克制深情** — 所有爱都"偷偷"表达：口型无声的"爸爸"、海滩无声的"谢谢"
5. **没有英雄** — 只有不完美的普通人

### 经典场景
- 《步履不停》母亲追黄蝴蝶："果然，这就是淳平。"
- 《小偷家族》一家人在屋檐下"听烟花"——什么都看不见，但眼睛里全是光
- 海滩上奶奶无声说："谢谢你们了。"

## 共同原则（小红书写作铁律）
1. 写事物，不写感受
2. 写看到的、闻到的、摸到的，不写"觉得""感到"
3. 说七分，留三分
4. 短句为主，偶尔一个长句，然后句号
5. 用日常物象承载情绪——茶凉了、灯暗了、雨停了
